RESTAURANT SALES & CUSTOMER ANALYTICS

SQL Data Analytics Project

PROBLEM STATEMENT

The restaurant generates a large amount of data related to customers, orders, menu items, payments, and feedback. However, this data is not being effectively analyzed to understand sales performance, customer behavior, menu performance, and payment patterns. This project aims to use SQL-based data analysis to transform the restaurant's raw data into meaningful business insights that can support better decision-making.


PROJECT OBJECTIVES

1. Analyze overall restaurant sales and revenue performance.
2. Identify sales trends over time.
3. Analyze customer purchasing behavior and spending patterns.
4. Identify the top-performing and underperforming menu items.
5. Analyze payment methods and payment performance.
6. Analyze customer feedback and ratings.
7. Identify meaningful business insights using SQL.
8. Build an interactive dashboard to present the key findings.

PROJECT SCOPE

This project will focus on analyzing restaurant data related to customers, menu items, orders, payments, and customer feedback. The analysis will cover sales performance, customer purchasing behavior, menu item performance, payment patterns, and customer satisfaction. SQL will be used for data management, cleaning, transformation, and analysis, while Power BI will be used to visualize the final insights through an interactive dashboard.

DATABASE TABLES

1. Customer
   Stores customer information.

2. Menu
   Stores restaurant menu item information.

3. Orders
   Stores information about customer orders.

4. OrderDetails
   Stores the individual menu items included in each order.

5. Payment
   Stores payment information for orders.

6. Feedback
   Stores customer ratings and feedback for orders.

CUSTOMER TABLE

CustomerID - Primary Key - Unique identifier for each customer
CustomerName - Name of the customer
PhoneNumber - Customer contact number
City - Customer's city
RegistrationDate - Date the customer registered

MENU TABLE
s
MenuID - Primary Key - Unique identifier for each menu item
ItemName - Name of the menu item
Category - Category of the menu item
Price - Selling price of the menu item


ORDERS TABLE

OrderID - Primary Key - Unique identifier for each order
CustomerID - Foreign Key - Identifies the customer who placed the order
OrderDate - Date on which the order was placed
OrderStatus - Current status of the order


ORDER DETAILS TABLE

OrderDetailID - Primary Key - Unique identifier for each order item record
OrderID - Foreign Key - Identifies the related order
MenuID - Foreign Key - Identifies the menu item ordered
Quantity - Number of units of the menu item ordered

PAYMENT TABLE

PaymentID - Primary Key - Unique identifier for each payment
OrderID - Foreign Key - Identifies the related order
PaymentDate - Date on which the payment was made
PaymentMethod - Method used for payment
PaymentAmount - Amount paid for the order
PaymentStatus - Status of the payment

FEEDBACK TABLE

FeedbackID - Primary Key - Unique identifier for each feedback record
OrderID - Foreign Key - Identifies the related order
Rating - Customer rating for the order
FeedbackDate - Date on which the feedback was provided
